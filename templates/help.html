Rules that actually match

The add/edit form lists extra operators. Only these are applied by the engine today:

  • label / label_in
  • category / category_in
  • state
  • ratio_gt
  • last_activity_hours_gt / last_activity_hours_gte
  • added_on_hours_gt / added_on_hours_gte

ratio_lt, size_*, tracker_contains, and progress_eq are shown in the form but are not evaluated yet.

Logs

Actions (qb-cleaner.log) — deletions, errors, service start/stop.

Schedule (qb-schedule.log) — every run started/finished, including empty passes.

Tray icon
  • Green — Windows service and web UI both running
  • Yellow — only one is up, or status unknown
  • Red — both stopped

Start the tray with start-tray.cmd (elevated) so Start/Stop service works. After an update, quit the tray and start it again.

Install and update

From the install folder, in an elevated prompt if UAC appears:

install.cmd
update.cmd
start-tray.cmd

Update does not overwrite rules.yaml, logs, or schedule_state.json. Do not copy a repo rules.yaml over production.
